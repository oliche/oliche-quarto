Overview

Brain-region classifiers trained on NP1 recordings are expected to transfer poorly to NP2 probes because:

  • NP2 uses tip referencing, which removes the low-frequency component below the tip.
  • Common Average Referencing (CAR) differs in spatial extent because NP2 records a shorter stretch of tissue.
  • Inter-channel spacing differs (NP1: 20 µm, NP2: 15 µm), which affects CSD-derived features.

The 2026_W24 feature vintage introduced two new columns — rms_lf_no_car and distance_to_tip_um — designed to make models more probe-agnostic. This report benchmarks Cosmos-level accuracy in five conditions:

Experiment Features Train → Test
Within-project 5-fold CV Vanilla NP1→NP1, NP2→NP2
Cross-project Vanilla NP1→NP2, NP2→NP1
Within-project 5-fold CV Enhanced (+rms_lf_no_car, distance_to_tip_um, axial_um) NP1→NP1, NP2→NP2
Cross-project Enhanced NP1→NP2, NP2→NP1

Data: ea_active / 2026_W24 (NP1, 383k channels), multi_area_comm / 2026_W24 (NP2, 126k channels). Target label: Cosmos regions (10 classes).

Baseline implementation review

The reference script (training_region_predictor_gradient_boosting.py) is solid. A few issues found:

  • localisation feature group returns [] in voltage_features_set — silently a no-op. Remove it from FEATURE_SET to avoid confusion.
  • device="gpu" crashes on CPU-only machines — added a detection/fallback in the script.
  • np.random.seed() returns None — the integer seed is never actually stored in meta; use np.random.default_rng(seed) instead.

Key findings

  1. Cross-probe transfer is catastrophic. Within-project CV reaches 57–68%; cross-probe drops to 19–30% — roughly halved. The confusion matrices show the model collapses to predicting a few dominant classes rather than generalising.

  2. New features do not rescue cross-probe transfer; they make NP1→NP2 worse (0.264 → 0.188). distance_to_tip_um and axial_um have very different distributions for NP1 vs NP2 (different recording lengths and geometries), creating distributional shift rather than removing it when transferring across probe types.

  3. The most important feature for NP1 (psd_theta_csd_diff1, importance 0.093) is a CSD feature — computed from spatial differences between adjacent channels, directly sensitive to inter-channel spacing (NP1: 20 µm vs NP2: 15 µm). NP2’s top feature is instead channel_labels (0.12), a discrete in/out-of-brain label. CSD features don’t even appear in NP2’s top 15 — tip referencing corrupts them near the tip.

  4. The combined model (train on NP1 + NP2 together) is the practical solution: it achieves ~0.60–0.63% across both probe types, close to the NP1 within-project baseline, without any probe-specific logic at inference time.

  5. NP2 has higher within-project accuracy than NP1 (0.663 vs 0.570 vanilla), despite having fewer channels (126k vs 292k). This likely reflects that multi_area_comm recordings are more tightly targeted to specific brain regions, giving a more separable class distribution.

  6. neuropixel_version as a feature barely helps the combined model (+0.002 accuracy). The feature distributions already implicitly encode probe type — adding it explicitly is redundant. The combined model is already doing probe-type-aware classification through the feature space.

Recommendations

For cross-probe generalisability:

  1. Remove CSD features (raw_lf_csd) from the cross-probe feature set — they depend on inter-channel spacing and are the main source of distribution shift.
  2. Use the combined model (train on both probe types together with neuropixel_version as a feature). This is the cleanest solution: one model that works for both probe types.
  3. Within-probe LFP normalisation: dividing LFP power features by their within-probe median would remove the absolute scale shift introduced by different gains and tip referencing.
  4. Domain adaptation (e.g. CORAL, adversarial training) could further close the gap if model accuracy on a specific probe type needs to be maximised.

Conclusion

The new 2026_W24 features (rms_lf_no_car, distance_to_tip_um) improve within-project accuracy but do not improve — and may worsen — cross-probe transfer. The root cause is that CSD features, which are among the most predictive for NP1, encode probe geometry rather than brain region. The recommended path forward is a combined NP1+NP2 training set (optionally with neuropixel_version as a feature), which achieves ~63% Cosmos accuracy on both probe types from a single model.
